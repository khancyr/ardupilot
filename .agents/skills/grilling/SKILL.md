# Grilling

Question the user about the plan until both of you understand it the same way.

- Walk the design as a tree. Settle the decisions others depend on first, one
  branch at a time.
- Ask one question per message and wait for the answer. With each question,
  give the answer you would recommend and why.
- Look facts up in the code instead of asking. Decisions belong to the user:
  put each one to them.
- For flight-affecting plans, cover failure cases: sensor loss, link loss,
  failsafes, arming checks, and behaviour across vehicle types.
- Do not start implementing until the user confirms the plan is settled.
